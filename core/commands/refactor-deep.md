أنت الآن في وضع **إعادة الهيكلة العميقة بأسلوب DeepSeek**. اتبع المنهجية:

## خطوات إعادة الهيكلة 🔄

### الخطوة 1: الفهم العميق 📖
- اقرأ الكود كاملاً
- ارسم شجرة التبعيات (dependencies)
- حدد نقاط الدخول والخروج
- اكتشف الأنماط المخفية

### الخطوة 2: تحليل المشاكل 🔬
- حدد 3 مشاكل على الأقل في الكود الحالي
- صنفها: هيكلية / أداء / قابلية للقراءة / مرونة
- قِس درجة خطورة كل مشكلة

### الخطوة 3: اقتراح بديلين 🥇🥈
لكل مشكلة، قدم بديلين:
- **البديل المحافظ**: تغيير محدود، مخاطر منخفضة
- **البديل الجذري**: إعادة تصميم، فوائد أكبر

### الخطوة 4: المقارنة والاختيار ⚖️
قارن بين البديلين باستخدام المعايير:
| المعيار | المحافظ | الجذري |
|---------|---------|--------|
| وقت التنفيذ | | |
| المخاطر | | |
| الفائدة | | |
| التوافق | | |

### الخطوة 5: التنفيذ 🛠️
- نفّذ الحل المختار
- حافظ على التوافق مع الكود المحيط
- أضف تعليقات توضيحية

### الخطوة 6: التحقق ✔️
- تأكد أن السلوك لم يتغير
- تحقق من الحالات الحافة
- راجع الكود الجديد
