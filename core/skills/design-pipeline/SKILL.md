# بوابة التصميم (Design Pipeline)

بوابة دخول واحدة لكل مهارات التصميم. بدل تذكر 20 مهارة منفصلة، هذه البوابة ترتّبها كمراحل — كل مرحلة بنوعها الصحيح، وتشير للمهارة الأصلية عند مرحلتها.

## قبل أي شيء: اقرأ المبادئ

اقرأ `principles.md` في نفس المجلد أولاً — المبادئ الجوهرية الـ 12 حاضرة طوال العمل.

## قاعدة الفصل (إلزامية)

- **نقاط الذوق** (الاتجاه البصري، الهوية، اللون الأساسي، المخاطرة الجمالية) = قرار المستخدم → **توقف واسأل**.
- **نقاط التقنية** (التباين، الطباعة، الحركة، الوصولية، الأداء، الاستجابة) = قرار التنفيذ → **طبّق بلا تردد**.

## الإيقافان الإجباريان (لا يُتجاوزان بصمت)

1. **إيقاف الاتجاه**: قبل البناء، اعرض الاتجاه البصري (أو عدة اتجاهات) وانتظر اختيار المستخدم.
2. **إيقاف الاعتماد**: بعد البناء والفحص، اعرض النتيجة وانتظر اعتماد المستخدم قبل اعتبار المهمة منتهية.

## قاعدة التطبيق

- لا تبدأ الكود قبل المرحلة 2 (الهوية) والموافقة على الاتجاه.
- المبادئ الجوهرية (principles.md) حاضرة طوال كل المراحل — لا تنتظر مرحلتها.
- عند انتهاء المراحل: أبلغ بالمهارات المستخدمة والمتخطاة وسبب التخطي.
