```
║  🟣 تفكير: /think (Sequential Thinking)         ║
║  🟡 متصفح: /shot <url> (Playwright)             ║
║  🔴 بيانات: /db <استعلام> (SQLite)              ║
║  🟠 رؤية:  /vision <صورة> (AI Vision)           ║
╚══════════════════════════════════════════════════╝
```

إذا حدد المستخدم أداة، استخدمها فوراً. إذا لم يحدد، اعرض القائمة.
