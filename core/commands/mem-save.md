أنت الآن في وضع **حفظ الذاكرة**. سجّل الجلسة الحالية بشكل كامل.

## آلية الحفظ 💾

### الخطوة 1: جمع المعلومات

اسأل المستخدم 3 أسئلة (اجمع الإجابات ثم تابع):

1. **ملخص الجلسة**: "وش أهم شيء أنجزته في هذي الجلسة؟" (سطر أو سطرين)
2. **هلوسات وأخطاء**: "هل لاحظت أي مسارات وهمية أو دوال غير موجودة أو مكتبات مختلقة؟" (إذا وجد، سجّل: النوع + القيمة المختلقة + السياق)
3. **قرارات معمارية**: "هل اتخذت أي قرار تقني أو معماري مهم يستحق التوثيق؟"

### الخطوة 2: إنشاء ملف الجلسة

**اختر الطبقة الصحيحة أولاً:**

| نوع المعرفة | الطبقة | المسار |
|---|---|---|
| ملخص جلسة · قرار معماري · حقيقة عن هذا الكود | مشروع | `~/.claude/projects/<معرّف-المسار-الحالي>/memory/` |
| تفضيل دائم · نمط فشل · هلوسة · قيد بيئة | عامة | `~/.claude/memory/` |

القاعدة: **هل تفيد هذه المعرفة في مشروع آخر؟** نعم → عامة، لا → مشروع. سيرة مشروع في الطبقة العامة تلوّث سياق بقية المشاريع.

اكتب ملف `session-YYYY-MM-DD-short-slug.md` في طبقة **المشروع** بهذا الهيكل:

```markdown
---
name: session-YYYY-MM-DD-slug
description: [ملخص الجلسة من سطر واحد]
metadata:
  node_type: memory
  type: session
  date: YYYY-MM-DD
  originSessionId: [session id الحالية]
---

# جلسة YYYY-MM-DD — [عنوان]

## الإنجازات

- [إنجاز 1]
- [إنجاز 2]

## الهلوسات المسجلة

- [إن وجدت، وإلا: "لا يوجد"]

## القرارات المعمارية

- [إن وجدت، وإلا: "لا يوجد"]
```

### الخطوة 3: تحديث MEMORY.md

أضف سطر الرابط في فهرس MEMORY.md تحت قسم "سجل الجلسات":

```markdown
- [جلسة YYYY-MM-DD — عنوان](session-YYYY-MM-DD-slug.md) — وصف سطر واحد
```

### الخطوة 4: مزامنة SQLite

شغّل:

```bash
node ~/.claude/scripts/sync-memory.js
```

### الخطوة 5: إذا وُجدت هلوسات

إذا سجل المستخدم هلوسات:

1. اقرأ `deepseek-hallucinations.md`
2. أضف حادثة جديدة تحت النمط المناسب (paths/functions/libraries/settings)
3. حدّث عداد `إجمالي الحوادث` وتاريخ `آخر تحديث`

### الخطوة 6: المخرجات النهائية

```
💾 تم حفظ الجلسة
   ├─ Markdown: session-YYYY-MM-DD-slug.md (X.XKB)
   ├─ MEMORY.md: محدّث ← X ملف
   ├─ SQLite: مزامنة ← X ذاكرة, X جلسة
   └─ هلوسات: X جديدة (الإجمالي: X)
```
