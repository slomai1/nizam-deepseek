أنت الآن في وضع **بناء سياق المشروع**. اتبع الخطوات:

## المرحلة 0: الاستكشاف 🔍

### الخطوة 1: حدد المشروع
```
المشروع الحالي = المجلد الذي تشتغل فيه الآن
```

### الخطوة 2: افحص هل فيه رسم بياني موجود
تحقق من وجود أحد هذين الملفين:
- `.understand-anything/knowledge-graph.json`
- `graphify-out/graph.json`

إذا كان `--full` → تجاهل وأعد البناء
إذا كان موجود → انتقل للمرحلة 2 (استعلام)
إذا كان غير موجود → تابع للمرحلة 1

---

## المرحلة 1: البناء 🏗️

### اختر الأداة المناسبة:

**إذا المشروع كود (أغلب الحالات):**
استدعِ مهارة `understand`:
```
/understand . --full --language ar
```
هذا:
- يحلل كل ملفات الكود
- يبني knowledge graph بـ nodes + edges + layers
- يولد `.understand-anything/knowledge-graph.json`

**إذا المشروع يحتوي وثائق/أبحاث/صور:**
استدعِ مهارة `graphify`:
```
/graphify . --mode deep
```

### بعد اكتمال البناء:
استخرج المعلومات التالية وخزنها في `PROJECT_CONTEXT.md`:

```markdown
# 🧠 سياق المشروع: [اسم المشروع]

## هيكلة المشروع
- [عدد] ملفات | [عدد] دوال | [عدد] كلاسات
- اللغات: [مثلاً TypeScript 60%, PHP 40%]

## المكونات الرئيسية
(من knowledge graph layers)
- [طبقة 1]: [وصف]
- [طبقة 2]: [وصف]

## المجال الوظيفي (Business Domain)
استخدم `understand-domain`:
- [مجال 1]: [وصف]
- [تدفق 1]: [خطوات]

## أكثر الملفات أهمية
(أعلى 10 ملفات حسب complexity أو connections)
1. `[مسار]` — [لماذا مهم]

## خريطة التبعيات
(من edges في الـ knowledge graph)
- [مكون أ] → يعتمد على → [مكون ب]

## نقاط ضعف محتملة
- ملفات عالية التعقيد (> 200 سطر)
- تبعيات دائرية
- كود مكرر
```

## المرحلة 2: الاستعلام 💬

مع `--chat <سؤال>`:
استخدم `understand-chat` للاستعلام عن الرسم البياني:
```
/understand-chat "<سؤال>"
```

## المرحلة 3: التحميل التلقائي 🚀

بعد بناء `PROJECT_CONTEXT.md`:
1. احفظه في جذر المشروع
2. أضف للمستخدم: "أضف هذا الملف لـ CLAUDE.md عشان يتحمل تلقائياً"
3. اقترح تشغيل `--auto-update` للتحديث التلقائي مع كل commit
