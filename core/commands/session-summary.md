أنت الآن في وضع **ملخص الجلسة**. لخّص الجلسة الحالية واحفظها في الذاكرة.

## هيكل الملخص 📋

### 🎯 الأهداف

- وش كان الهدف الرئيسي من الجلسة؟
- هل تحقق الهدف؟ (بالكامل / جزئياً / لم يتحقق)

### 📝 القرارات المهمة

- (أي قرارات معمارية أو تقنية تم اتخاذها)
- (لماذا اخترنا X على Y؟)

### 📁 الملفات المتأثرة

- اذكر كل ملف تم تعديله أو إنشاؤه
- مع سبب التعديل

### 🐛 أخطاء وتصحيحات

- أخطاء واجهتها
- كيف تم حلها
- الدروس المستفادة

### 💡 للجلسة القادمة

- وش باقي يشتغل؟
- أولويات الجلسة القادمة

## الحفظ

بعد كتابة الملخص، احفظه في:

```
~/.claude/projects/<معرّف-مشروعك>/memory/sessions/YYYY-MM-DD-<وصف>.md
```

وأضف رابطه في `MEMORY.md` الرئيسي تحت قسم "الجلسات".

ثم أكد:

```
✅ تم حفظ ملخص الجلسة — [عدد] قرارات، [عدد] ملفات، [عدد] دروس
```
