## 📋 استخدام الذاكرة

- **التحميل:** `/mem-load` (بداية الجلسة) · **الحفظ:** `/mem-save` (نهاية الجلسة) · **الاستعلام:** `/mem-query`
- **إضافة ذاكرة عادية:** أنشئ `.md` مع frontmatter → أضف رابطاً في الفهرس → شغّل `node ~/.claude/scripts/sync-memory.js`
- **إضافة هلوسة:** أدرجها في جدول `hallucinations` في SQLite (المصدر)

## 🗄️ التخزين

- **مصدر الحقيقة**: Markdown (هذا المجلد) — يُقرأ تلقائياً عند بدء الجلسة
- **مخزن الاستعلامات**: SQLite في `~/.claude/data/deepseek.db`
- **المزامنة**: `node ~/.claude/scripts/sync-memory.js` — ثنائية الاتجاه: `memories` من Markdown → SQLite (المصدر Markdown)، و`hallucinations`/`tool_usage` من SQLite → Markdown (المصدر SQLite)
